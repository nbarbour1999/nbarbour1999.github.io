Welcome to my site repo

Here you will find my Jekyll site hosted with Github pages

In docs you will find the following:
  -Posts
  -Layouts
  -Includes
  -Assets

Posts contain general posts on the site that contain messages and some other updates.

Layouts include the layout HTML layouts of my site. The use a mix of the Minima theme as well as changes to fit my needs as I work on this project.

Includes are different HTML files that help handle the logic of the site

Assets contain different media and info that I use thoughout my site
